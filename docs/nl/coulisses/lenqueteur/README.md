# 🔍 De onderzoeker

**Haar vak**: het dossier van elk bedrijf aanvullen met zijn **openbare**
informatie — de website, het telefoonnummer, de sociale netwerken.

Ze zoekt alleen wat het bedrijf zelf aan het grote publiek toont.
Niets privé, niets geheim, niets dat achter een wachtwoord zit.

## Wat ze aan het dossier toevoegt

| Informatie | Waar ze vandaan komt |
|---|---|
| Website | Wat het bedrijf openbaar toont |
| Telefoonnummer | Openbaar nummer |
| Sociale netwerken | Openbare links (LinkedIn, Instagram...) |
| Aanwezigheid op de kaart | Gecontroleerd door de geograaf |
| Hoedanigheden van bestuurders | Officiële openbare registers ("President van SAS", "Zaakvoerder"...) |

## Haar beloften

| Belofte | Detail |
|---|---|
| Alleen openbaar | Nooit privé- of beschermde gegevens |
| Stapsgewijs | De dossiers worden in de loop van de tijd rijker |
| Verifieerbaar | Elk gegeven wordt getoond met zijn bron |
