# 🧩 De personenpuzzel

**Zijn vak**: elke persoon terugvinden die in de bekendmakingen voorkomt —
bestuurders, vereffenaars, commissarissen, kopers, verkopers — en hem
verbinden met zijn bedrijven.

Dankzij hem kunnen we eenvoudige vragen beantwoorden:
- "Welke bedrijven leidt deze persoon?"
- "Wie zit er achter deze vennootschap?"
- "Sinds wanneer?"

## Wat we vandaag weten

| Cijfer | Detail |
|---|---|
| Personendossiers | 2 684 424 |
| Natuurlijke personen | De grote meerderheid (naam + voornaam) |
| Besturende vennootschappen | ~1 miljoen (een vennootschap kan een andere besturen) |
| Bestuurders gekoppeld aan hun dossier | Meer dan 186 000 in de profielen |

## Hoe hij werkt

1. Hij leest elke bekendmaking en spoort de vermelde personen op.
2. Hij controleert of de persoon al bestaat (zelfde naam, zelfde voornaam).
3. Hij verbindt hem met het bedrijf en de functie (president, zaakvoerder...).
4. Hij vult het dossier aan met de officiële hoedanigheden.
