# 🗺️ De geograaf

**Zijn vak**: controleren dat elk bedrijf echt bestaat op de wereldkaart
(Google Maps) en noteren wat we er zien: het adres, de categorie, de
beoordeling, het aantal recensies, de website, het telefoonnummer.

Dankzij hem toont een bedrijfsdossier ook zijn **reële aanwezigheid** in het
echte leven, niet alleen zijn officiële papieren.

## Wat hij noteert

| Informatie | Detail |
|---|---|
| Adres op de kaart | Waar het bedrijf echt is |
| Categorie | Horeca, handel, diensten... |
| Beoordeling en recensies | Wat klanten openbaar zeggen |
| Website / telefoon | Geverifieerd op het openbare dossier |
