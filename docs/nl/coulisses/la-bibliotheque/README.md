# 📚 De contractenbibliotheek

**Zijn vak**: de Franse **overheidsopdrachten** in onze bibliotheek opbergen —
de contracten die door overheidsdiensten, lokale overheden en openbare
bedrijven worden gegund.

Elk contract wordt gearchiveerd met de belangrijke informatie: wie koopt,
wie levert, voor welk bedrag, voor welke opdracht.

**Vandaag: meer dan een miljoen contracten, van 2015 tot nu.**

## Wat de bibliotheek bevat

| Informatie | Detail |
|---|---|
| Wie koopt | De lokale overheid of de administratie |
| Wie levert | Het bedrijf dat het contract heeft gewonnen |
| Bedrag | De prijs van het contract |
| Opdracht | Wat er is gekocht (geclassificeerd per code) |
| Datum | Wanneer het contract is gegund |

## Zijn beloften

| Belofte | Detail |
|---|---|
| Volledig | Sinds 2015, elke dag bijgewerkt |
| Openbaar | Vrij en gratis te raadplegen |
| Gekoppeld | De contracten worden waar mogelijk aan bedrijven gekoppeld |
