# 🧩 El rompecabezas de personas

**Su oficio**: encontrar a cada persona que aparece en los anuncios —
directivos, liquidadores, comisarios de cuentas, compradores, vendedores — y
vincularla con sus empresas.

Gracias a él, podemos responder a preguntas sencillas:
- «¿Qué empresas dirige esta persona?»
- «¿Quién está detrás de esta sociedad?»
- «¿Desde cuándo?»

## Cómo trabaja

1. Lee cada anuncio y localiza a las personas citadas.
2. Comprueba si la persona ya existe (mismo nombre, mismo apellido).
3. La vincula a la empresa y al cargo (presidente, gerente...).
4. Completa la ficha con los cargos oficiales.
