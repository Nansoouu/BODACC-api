# 📚 La biblioteca de contratos

**Su oficio**: archivar en nuestra biblioteca los **contratos públicos** de
Francia — los contratos celebrados por las administraciones, las colectividades
y las empresas públicas.

Cada contrato se archiva con la información importante: quién compra,
quién suministra, por qué importe, para qué misión.

**Hoy: más de un millón de contratos, de 2015 hasta nuestros días.**

## Lo que contiene la biblioteca

| Información | Detalle |
|---|---|
| Quién compra | La colectividad o la administración |
| Quién suministra | La empresa que ganó el contrato |
| Importe | El precio del contrato |
| Misión | Lo que se compró (clasificado por código) |
| Fecha | Cuándo se adjudicó el contrato |

## Sus promesas
