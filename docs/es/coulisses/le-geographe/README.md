# 🗺️ El geógrafo

**Su oficio**: comprobar que cada empresa existe realmente en el mapa del
mundo (Google Maps) y anotar lo que se ve: la dirección, la categoría, la
nota, el número de opiniones, el sitio web, el teléfono.

Gracias a él, una ficha de empresa muestra también su **presencia real** en la
vida real, no solo sus papeles oficiales.

## Qué anota

| Información | Detalle |
|---|---|
| Dirección en el mapa | Dónde se encuentra realmente la empresa |
| Categoría | Restauración, comercio, servicios... |
| Nota y opiniones | Lo que los clientes dicen públicamente |
| Sitio web / teléfono | Verificados en la ficha pública |
