# 🔍 La investigadora

**Su oficio**: completar la ficha de cada empresa con su información
**pública** — su sitio web, su teléfono, sus redes sociales.

Solo busca lo que la propia empresa muestra al gran público.
Nada privado, nada secreto, nada que esté detrás de una contraseña.

## Qué añade a la ficha

| Información | De dónde viene |
|---|---|
| Sitio web | Lo que la empresa muestra públicamente |
| Teléfono | Número público |
| Redes sociales | Enlaces públicos (LinkedIn, Instagram...) |
| Presencia en el mapa | Verificada por el geógrafo |
| Cargos de los directivos | Registros públicos oficiales («Presidente de SAS», «Gerente»...) |

## Sus promesas

| Promesa | Detalle |
|---|---|
| Solo público | Nunca datos privados o protegidos |
| Progresivo | Las fichas se enriquecen con el tiempo |
| Verificable | Cada dato se muestra con su fuente |
