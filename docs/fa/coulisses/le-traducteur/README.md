# 📖 مترجم

**شغل او**: خواندن هر اطلاعیه رسمی و تبدیل آن به کارتی روشن و قابل فهم: نام شرکت، آدرس آن، فعالیت آن، مدیران آن، مبالغ، تاریخها...

اطلاعیه رسمی متنی اداری است که اغلب طولانی و پیچیده است. مترجم آن را به کارتی تبدیل میکند که همه میتوانند بخوانند — یک کودک ۷ ساله یا یک بانکدار.

## کاری که انجام میدهد

1. هر اطلاعیه را از ابتدا تا انتها میخواند.
2. اطلاعات مهم را استخراج میکند: چه کسی، چه چیزی، کجا، کی، چقدر.
3. نتیجه را در کارت شرکت مربوطه مرتب میکند.
