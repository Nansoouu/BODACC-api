# 🌅 پستچی صبح

**شغل او**: هر صبح، خیلی زود، جمع‌آوری همه اطلاعیه‌های رسمی شرکت‌های فرانسوی که روز قبل منتشر شده‌اند و آوردن آن‌ها به خانه، بدون اینکه حتی یکی گم شود.

او **اولین قدم** داستان ماست: بدون او، هیچ چیز نمی‌توانست به صفحه شما برسد.

## کاری که هر روز انجام می‌دهد

1. برای بردن اطلاعیه‌های رسمی می‌رود (تأسیس، تغییرات، حذف از ثبت، رویه‌ها، فروش، تسلیم حساب‌ها...).
2. آن‌ها را برمی‌گرداند و با دقت در کتابخانه مرتب می‌کند.
3. به مترجم خبر می‌دهد: «کار هست!»
