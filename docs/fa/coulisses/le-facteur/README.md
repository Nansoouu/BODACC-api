# 🌅 پستچی صبح

**شغل او**: هر صبح، خیلی زود، جمعآوری تمام اطلاعیههای رسمی شرکتهای فرانسوی که روز قبل منتشر شدهاند و آوردن آنها به خانه — بدون از دست دادن حتی یکی.

او **اولین مرحله** داستان ماست: بدون او، هیچ چیز نمیتوانست به صفحهنمایش شما برسد.

## کاری که هر روز انجام میدهد

1. برای جمعآوری اطلاعیههای رسمی میرود (تأسیس، تغییرات، ابطال، مراحل، فروش، ثبت حسابها...).
2. آنها را برمیگرداند و با دقت در کتابخانه مرتب میکند.
3. به مترجم خبر میدهد: «کار داریم!»
