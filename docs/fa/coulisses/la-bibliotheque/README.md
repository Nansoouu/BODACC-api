# 📚 کتابخانه قراردادها

**شغل او**: مرتب کردن **قراردادهای عمومی** فرانسه در کتابخانه ما — قراردادهایی که توسط ادارات، نهادهای محلی و شرکتهای عمومی منعقد میشوند.

هر قرارداد با اطلاعات مهم بایگانی میشود: چه کسی خریداری میکند، چه کسی تأمین میکند، با چه مبلغی، برای چه مأموریتی.

**امروز: بیش از یک میلیون قرارداد، از 2015 تا امروز.**
