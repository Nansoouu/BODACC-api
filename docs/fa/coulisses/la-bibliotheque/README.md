# 📚 کتابخانه قراردادها

**شغل او**: مرتب کردن **مناقصه‌های عمومی** فرانسه در کتابخانه ما — قراردادهایی که توسط ادارات، نهادهای محلی و شرکت‌های عمومی منعقد می‌شوند.

هر قرارداد با اطلاعات مهم بایگانی می‌شود: چه کسی خریداری می‌کند، چه کسی تأمین می‌کند، با چه مبلغی، برای چه مأموریتی.

**امروز: بیش از یک میلیون قرارداد، از 2015 تا امروز.**

## کتابخانه چه چیزهایی دارد

| اطلاعات | جزئیات |
|---|---|
| چه کسی خریداری می‌کند | نهاد محلی یا اداره |
| چه کسی تأمین می‌کند | شرکتی که قرارداد را برنده شده |
| مبلغ | قیمت قرارداد |
| مأموریت | چه چیزی خریداری شده (طبقه‌بندی بر اساس کد) |
| تاریخ | چه زمانی قرارداد اعطا شده |
