# 🧭 کاوشگر

**شغل او**: پس از آنکه پستچی، مترجم، محقق و کتابدار کار خود را انجام دادند، کاوشگر درها را باز می‌کند. او داده‌های جمع‌آوری‌شده را به **نماها، آمارها و خلاصه‌ها** تبدیل می‌کند که همه می‌توانند بدون متخصص بودن از آن‌ها استفاده کنند.

او **آخرین مرحله** داستان ماست: کسی که داده‌ها را تا صفحه شما می‌آورد.

## او هر روز چه می‌کند

1. او اطلاعیه‌ها را بر اساس موضوع مرتب می‌کند (تأسیس، تغییرات، حذف، فروش، سپرده‌گذاری حساب‌ها...) تا به‌راحتی پیدا شوند.
2. او **شمارنده‌های زنده** و خلاصه روز را آماده می‌کند: چند اطلاعیه رسیده است، کدام دسته بیشترین تعداد را دارد.
3. او درهای کتابخانه را به روی عموم باز می‌کند: کارت‌های شرکت‌ها، افراد، مناطق، و خلاصه روز.
