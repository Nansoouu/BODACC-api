# 🧩 پازل افراد

**شغل او**: یافتن هر فردی که در اطلاعیهها ظاهر میشود — مدیران، تصفیهکنندگان، حسابرسان، خریداران، فروشندگان — و پیوند دادن او به شرکتهایش.

به لطف او، میتوانیم به سؤالات ساده پاسخ دهیم:
- «این شخص چه شرکتهایی را اداره میکند؟»
- «چه کسی پشت این شرکت است؟»
- «از چه زمانی؟»
