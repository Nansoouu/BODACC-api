# 🧩 Пазл людей

**Его работа**: найти каждого человека, который появляется в объявлениях —
руководителей, ликвидаторов, аудиторов, покупателей, продавцов — и связать
его с его компаниями.

Благодаря ему мы можем отвечать на простые вопросы:
- "Какими компаниями руководит этот человек?"
- "Кто стоит за этой компанией?"
- "С каких пор?"

## Как он работает

1. Он читает каждое объявление и замечает упомянутых людей.
2. Он проверяет, существует ли человек (та же фамилия, то же имя).
3. Он связывает его с компанией и должностью (президент, управляющий...).
4. Он дополняет карточку официальными должностями.
