# 🧭 Исследователь

**Его работа**: когда почтальон, переводчик, исследовательница и библиотекарь
сделали своё дело, исследователь открывает двери. Он превращает собранные
данные в **страницы, статистику и сводки**, которые может просматривать
каждый — без необходимости быть экспертом.

Он — **последний этап** нашей истории: тот, кто доносит данные до вашего
экрана.

## Что он делает каждый день

1. Он раскладывает объявления по темам (создания, изменения, прекращения,
   продажи, сдача отчётности...), чтобы легко было ориентироваться.
2. Он готовит **счётчики в реальном времени** и сводку дня: сколько
   объявлений поступило, какая категория самая многочисленная.
3. Он открывает двери библиотеки для публики: карточки компаний, людей,
   регионов и итоговую сводку дня.
