# 🔍 Исследовательница

**Её работа**: дополнять карточку каждой компании её **публичной**
информацией — сайтом, телефоном, соцсетями.

Она ищет только то, что компания сама показывает широкой публике.
Ничего частного, ничего секретного, ничего, что скрыто за паролем.

## Что она добавляет в карточку

| Информация | Откуда она берётся |
|---|---|
| Сайт | То, что компания показывает публично |
| Телефон | Публичный номер |
| Соцсети | Публичные ссылки (LinkedIn, Instagram...) |
| Присутствие на карте | Проверено географом |
| Должности руководителей | Официальные публичные реестры ("Президент SAS", "Управляющий"...) |
