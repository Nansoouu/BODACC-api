# 🌅 Утренний почтальон

**Его работа**: каждое утро, очень рано, собрать все официальные
объявления французских компаний, опубликованные накануне, и принести их
домой — не теряя ни одного.

Это **первый шаг** нашей истории: без него ничто не смогло бы попасть на
ваш экран.

## Что он делает каждый день

1. Он отправляется за официальными объявлениями (создания, изменения,
   исключения из реестра, процедуры, продажи, сдача отчётности...).
2. Он приносит их и аккуратно раскладывает в библиотеке.
3. Он предупреждает переводчика: "есть работа!"

## Его обещания

| Обещание | Подробности |
|---|---|
| Каждое утро | Объявления за предыдущий день доступны до 9 часов |
| Ничего не теряется | Повторный проход никогда не создаёт дубликат |
| Вся история | Мы доходим до 2008 года, а не только до последних дней |
