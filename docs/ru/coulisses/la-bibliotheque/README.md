# 📚 Библиотека контрактов

**Его работа**: раскладывать в нашей библиотеке французские
**государственные контракты** — договоры, заключаемые администрациями,
муниципалитетами и государственными предприятиями.

Каждый контракт архивируется с важной информацией: кто покупает, кто
поставляет, на какую сумму, для какой задачи.

**Сегодня: более миллиона контрактов, с 2015 года по наши дни.**

## Что содержит библиотека

| Информация | Подробности |
|---|---|
| Кто покупает | Муниципалитет или администрация |
| Кто поставляет | Компания, выигравшая контракт |
| Сумма | Цена контракта |
| Задача | Что было куплено (классифицировано по коду) |
| Дата | Когда контракт был заключён |
