# 📖 Le traducteur

**Son métier** : lire chaque annonce officielle et la transformer en fiche
claire et compréhensible : le nom de l'entreprise, son adresse, son activité,
ses dirigeants, les montants, les dates...

Une annonce officielle est un texte administratif, souvent long et compliqué.
Le traducteur en fait une fiche que tout le monde peut lire — un enfant de
7 ans comme un banquier.

## Ce qu'il fait

1. Il lit chaque annonce de bout en bout.
2. Il en sort les informations importantes : qui, quoi, où, quand, combien.
3. Il range le résultat dans la fiche de l'entreprise concernée.

## Les types d'annonces qu'il sait lire

| Type | Ce qu'on apprend | Exemples lus à ce jour |
|---|---|---|
| Dépôts de comptes | Les comptes annuels déposés, à temps ou en retard | ~9 millions |
| Modifications | Changements de dirigeants, de capital, transferts | ~2,6 millions |
| Créations | Naissance de l'entreprise : capital, adresse, fondateurs | ~2,4 millions |
| Radiations | Fin d'activité, durée de vie de l'entreprise | ~1,6 million |
| Procédures collectives | Sauvegarde, redressement, liquidation | ~820 000 |
| Ventes & cessions | Vente d'un fonds : prix, vendeur, acheteur | ~230 000 |
| Immatriculations | Inscription au registre, transferts de greffe | ~213 000 |
| Conciliations | Accords amiables | ~1 000 |
| Rétablissements | Retours à l'activité | ~680 |
| Divers | Saisies, nullités | quelques-unes |

**Au total : chaque annonce jamais publiée depuis 2004 a été lue et rangée.**
