# 🌅 Le facteur du matin

**Son métier** : chaque matin, très tôt, récupérer toutes les annonces
officielles des entreprises françaises publiées la veille, et les ramener à la
maison, sans en perdre une seule.

C'est la **première étape** de notre histoire : sans lui, rien ne pourrait
arriver jusqu'à votre écran.

## Ce qu'il fait chaque jour

1. Il part chercher les annonces officielles (créations, modifications,
   radiations, procédures, ventes, dépôts de comptes...).
2. Il les rapporte et les range soigneusement dans la bibliothèque.
3. Il prévient le traducteur : « il y a du travail ! »
