# 📚 La bibliothèque des contrats

**Son métier** : ranger dans notre bibliothèque les **marchés publics** de
France — les contrats passés par les administrations, les collectivités et les
entreprises publiques.

Chaque contrat est archivé avec les informations importantes : qui achète,
qui fournit, pour quel montant, pour quelle mission.

**Aujourd'hui : plus d'un million de contrats, de 2015 à nos jours.**

## Ce que la bibliothèque contient

| Information | Détail |
|---|---|
| Qui achète | La collectivité ou l'administration |
| Qui fournit | L'entreprise qui a gagné le contrat |
| Montant | Le prix du contrat |
| Mission | Ce qui a été acheté (classé par code) |
| Date | Quand le contrat a été attribué |
