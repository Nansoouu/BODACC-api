# 📚 合同图书馆

**他的工作**：把法国的**公共采购** — 行政部门、地方政府和公营企业签订的合同 — 归档进我们的图书馆。

每份合同都连同重要信息一起存档：谁采购、谁供货、金额多少、任务是什么。

**今天：从 2015 年至今，超过一百万份合同。**

## 图书馆里有什么

| 信息 | 详情 |
|---|---|
| 谁采购 | 地方政府或行政部门 |
| 谁供货 | 中标的企业 |
| 金额 | 合同价格 |
| 任务 | 采购的内容（按代码分类） |
| 日期 | 合同授予的时间 |

## 他的承诺

| 承诺 | 详情 |
|---|---|
| 完整 | 自 2015 年起，每天更新 |
| 公开 | 可自由、免费查阅 |
| 关联 | 尽可能将合同与企业关联 |
