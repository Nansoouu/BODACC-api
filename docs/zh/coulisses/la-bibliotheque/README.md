# 📚 合同图书馆

**他的工作**：将法国的**公共采购**——行政部门、地方政府和公共企业签订的合同——归档到我们的图书馆中。

每份合同都连同重要信息一起存档：谁购买、谁供应、金额多少、任务是什么。

**今天：从2015年至今，超过一百万份合同。**

## 图书馆包含的内容

| 信息 | 详情 |
|---|---|
| 谁购买 | 地方政府或行政部门 |
| 谁供应 | 中标的企业 |
| 金额 | 合同价格 |
| 任务 | 采购的内容（按代码分类） |
| 日期 | 合同授予的时间 |

## 他的承诺

| 承诺 | 详情 |
