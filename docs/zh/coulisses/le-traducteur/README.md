# 📖 翻译员

**他的工作**：阅读每则官方公告，并把它转换成清晰易懂的卡片：企业名称、地址、业务、高管、金额、日期…。

官方公告是一种行政文本，往往又长又复杂。翻译员把它变成任何人都能读的卡片 — 7 岁的孩子或银行家都可以。

## 他做的事

1. 从头到尾阅读每则公告。
2. 提取重要信息：谁、什么、哪里、何时、多少。
3. 把结果整理进相关企业的卡片。
