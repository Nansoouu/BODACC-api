# 📖 翻译员

**他的工作**：阅读每一条官方公告，并将其转化为清晰易懂的档案：公司名称、地址、业务、高管、金额、日期……

官方公告是行政文本，往往冗长而复杂。翻译员将其转化为任何人都能阅读的档案——无论是7岁的孩子还是银行家。

## 他做的事

1. 从头到尾阅读每一条公告。
2. 提取重要信息：谁、什么、哪里、何时、多少。
3. 将结果归档到相关公司的档案中。
