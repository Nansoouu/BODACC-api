# 🗺️ 地理学家

**他的工作**：核实每家公司是否真实存在于世界地图上（谷歌地图），并记录所见内容：地址、类别、评分、评论数量、网站、电话。

有了他，公司档案还能展示其在现实世界中的**真实存在**，而不仅仅是官方文件。

## 他记录的内容

| 信息 | 详情 |
|---|---|
| 地图上的地址 | 公司实际所在位置 |
| 类别 | 餐饮、零售、服务…… |
| 评分与评论 | 客户公开的评价 |
| 网站 / 电话 | 已在公开档案中核实 |

## 他的承诺

| 承诺 | 详情 |
