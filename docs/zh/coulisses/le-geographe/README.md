# 🗺️ 地理学家

**他的工作**：核实每家企业是否真实存在于世界地图（Google Maps）上，并记录看到的内容：地址、类别、评分、评论数、网站、电话。

有了他，企业卡片也展示了其在现实世界中的**真实存在**，而不仅仅是官方文件。

## 他记录的内容

| 信息 | 详情 |
|---|---|
| 地图上的地址 | 企业真正所在的位置 |
| 类别 | 餐饮、商业、服务… |
| 评分与评论 | 客户公开说的话 |
| 网站 / 电话 | 已在公开卡片上核实 |
