# 📚 A biblioteca de contratos

**O seu ofício**: arquivar na nossa biblioteca os **contratos públicos** de
França — os contratos celebrados pelas administrações, pelas autarquias
e pelas empresas públicas.

Cada contrato é arquivado com as informações importantes: quem compra,
quem fornece, por que montante, para que missão.

**Hoje: mais de um milhão de contratos, de 2015 até hoje.**

## O que a biblioteca contém

| Informação | Detalhe |
|---|---|
| Quem compra | A autarquia ou a administração |
| Quem fornece | A empresa que ganhou o contrato |
| Montante | O preço do contrato |
| Missão | O que foi comprado (classificado por código) |
| Data | Quando o contrato foi atribuído |

## As suas promessas
