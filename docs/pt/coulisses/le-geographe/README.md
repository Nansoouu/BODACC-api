# 🗺️ O geógrafo

**O seu ofício**: verificar se cada empresa existe mesmo no mapa do
mundo (Google Maps) e anotar o que se vê: a morada, a categoria, a
avaliação, o número de opiniões, o site, o telefone.

Graças a ele, uma ficha de empresa mostra também a sua **presença real** na
vida real, não apenas os seus papéis oficiais.

## O que anota

| Informação | Detalhe |
|---|---|
| Morada no mapa | Onde a empresa está realmente |
| Categoria | Restauração, comércio, serviços... |
| Avaliação e opiniões | O que os clientes dizem publicamente |
| Site / telefone | Verificados na ficha pública |
