# 🌅 O carteiro da manhã

**O seu ofício**: todas as manhãs, bem cedo, recolher todos os anúncios
oficiais das empresas francesas publicados no dia anterior e trazê-los para
casa, sem perder nenhum.

É o **primeiro passo** da nossa história: sem ele, nada poderia
chegar até ao seu ecrã.

## O que faz todos os dias

1. Vai buscar os anúncios oficiais (criações, modificações,
   radiações, processos, vendas, depósitos de contas...).
2. Traz-los e arquiva-os cuidadosamente na biblioteca.
3. Avisa o tradutor: «há trabalho!»

## As suas promessas

| Promessa | Detalhe |
|---|---|
| Todas as manhãs | Os anúncios do dia anterior estão disponíveis antes das 9 h |
| Nada se perde | Passar duas vezes nunca cria um duplicado |
| Todo o histórico | Chegamos até 2008, não só aos últimos dias |
