# 🧩 O quebra-cabeça de pessoas

**O seu ofício**: encontrar cada pessoa que aparece nos anúncios —
dirigentes, liquidatários, revisores oficiais de contas, compradores, vendedores — e
ligá-la às suas empresas.

Graças a ele, podemos responder a perguntas simples:
- «Que empresas dirige esta pessoa?»
- «Quem está por detrás desta sociedade?»
- «Desde quando?»

## Como trabalha

1. Lê cada anúncio e identifica as pessoas citadas.
2. Verifica se a pessoa já existe (mesmo nome, mesmo apelido).
3. Liga-a à empresa e ao cargo (presidente, gerente...).
4. Completa a ficha com as qualificações oficiais.
