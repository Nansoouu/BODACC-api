# 🧭 O explorador

**O seu ofício**: depois de o carteiro, o tradutor, a investigadora e o
bibliotecário terem feito a sua parte, o explorador abre as portas. Transforma
os dados recolhidos em **vistas, estatísticas e resumos** que toda a gente pode
consultar, sem ser especialista.

É o **último passo** da nossa história: aquele que leva os dados até ao teu
ecrã.

## O que faz todos os dias

1. Organiza os anúncios por tema (criações, modificações, radiações, vendas,
   depósitos de contas...) para que seja fácil encontrar o que se procura.
2. Prepara os **contadores em direto** e o resumo do dia: quantos anúncios
   chegaram, qual é a família mais numerosa.
3. Abre as portas da biblioteca ao público: fichas de empresas, pessoas,
   regiões e o resumo do dia.
