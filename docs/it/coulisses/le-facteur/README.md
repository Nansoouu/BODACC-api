# 🌅 Il postino del mattino

**Il suo mestiere**: ogni mattina, molto presto, recuperare tutti gli annunci
ufficiali delle imprese francesi pubblicati il giorno prima e riportarli a
casa, senza perderne nemmeno uno.

È il **primo passo** della nostra storia: senza di lui, niente potrebbe
arrivare fino al vostro schermo.

## Cosa fa ogni giorno

1. Va a recuperare gli annunci ufficiali (creazioni, modifiche,
   cancellazioni, procedure, vendite, depositi di bilanci...).
2. Li riporta e li archivia con cura nella biblioteca.
3. Avvisa il traduttore: «c'è lavoro!»
