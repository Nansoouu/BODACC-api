# 🔍 La ricercatrice

**Il suo mestiere**: completare la scheda di ogni impresa con le sue informazioni
**pubbliche** — il suo sito web, il suo telefono, i suoi social network.

Cerca solo ciò che l'impresa mostra da sola al grande pubblico.
Niente di privato, niente di segreto, niente che sia dietro una password.

## Cosa aggiunge alla scheda

| Informazione | Da dove viene |
|---|---|
| Sito web | Ciò che l'impresa mostra pubblicamente |
| Telefono | Numero pubblico |
| Social network | Link pubblici (LinkedIn, Instagram...) |
| Presenza sulla mappa | Verificata dal geografo |
| Qualifiche dei dirigenti | Registri pubblici ufficiali («Presidente di SAS», «Amministratore»...) |
