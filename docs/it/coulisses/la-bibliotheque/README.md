# 📚 La biblioteca dei contratti

**Il suo mestiere**: archiviare nella nostra biblioteca gli **appalti pubblici**
della Francia — i contratti stipulati dalle amministrazioni, dagli enti locali
e dalle imprese pubbliche.

Ogni contratto è archiviato con le informazioni importanti: chi acquista,
chi fornisce, per quale importo, per quale missione.

**Oggi: più di un milione di contratti, dal 2015 a oggi.**

## Cosa contiene la biblioteca

| Informazione | Dettaglio |
|---|---|
| Chi acquista | L'ente locale o l'amministrazione |
| Chi fornisce | L'impresa che ha vinto il contratto |
| Importo | Il prezzo del contratto |
| Missione | Ciò che è stato acquistato (classificato per codice) |
| Data | Quando è stato aggiudicato il contratto |

## Le sue promesse

| Promessa | Dettaglio |
|---|---|
