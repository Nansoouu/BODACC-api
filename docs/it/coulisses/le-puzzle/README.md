# 🧩 Il puzzle delle persone

**Il suo mestiere**: ritrovare ogni persona che appare negli annunci —
dirigenti, liquidatori, revisori dei conti, acquirenti, venditori — e
collegarla alle sue imprese.

Grazie a lui, possiamo rispondere a domande semplici:
- «Quali imprese dirige questa persona?»
- «Chi c'è dietro questa società?»
- «Da quando?»

## Come lavora

1. Legge ogni annuncio e individua le persone citate.
2. Verifica se la persona esiste già (stesso nome, stesso cognome).
3. La collega all'impresa e alla carica (presidente, amministratore...).
4. Completa la scheda con le qualifiche ufficiali.
