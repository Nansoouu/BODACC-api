# 🗺️ Coğrafyacı

**İşi**: her şirketin dünya haritasında (Google Maps) gerçekten var olup
olmadığını doğrulamak ve orada gördüklerimizi not etmek: adres, kategori,
puan, yorum sayısı, web sitesi, telefon.

Onun sayesinde bir şirket kaydı, yalnızca resmî evraklarını değil, gerçek
hayattaki **gerçek varlığını** da gösterir.

## Not ettikleri

| Bilgi | Ayrıntı |
|---|---|
| Haritadaki adres | Şirketin gerçekte bulunduğu yer |
| Kategori | Restoran, ticaret, hizmetler... |
| Puan ve yorumlar | Müşterilerin kamuya açık söyledikleri |
| Web sitesi / telefon | Kamuya açık kayıtta doğrulanır |

## Sözleri

| Söz | Ayrıntı |
|---|---|
| Yalnızca kamuya açık | Herkesin görebildiklerinden başka bir şey yok |
| Kampanyalarla | Şirket listelerini gruplar hâlinde inceler |
| Saygılı | Kimseyi rahatsız etmemek için yavaş ilerler |
