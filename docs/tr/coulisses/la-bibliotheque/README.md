# 📚 Sözleşme Kütüphanesi

**İşi**: kütüphanemize Fransız **kamu ihalelerini** yerleştirmek — idareler,
yerel yönetimler ve kamu şirketleri tarafından verilen sözleşmeler.

Her sözleşme önemli bilgilerle arşivlenir: kim satın alıyor, kim tedarik
ediyor, hangi tutar için, hangi görev için.

**Bugün: 2015'ten günümüze bir milyondan fazla sözleşme.**

## Kütüphanenin içeriği

| Bilgi | Ayrıntı |
|---|---|
| Kim satın alıyor | Yerel yönetim veya idare |
| Kim tedarik ediyor | Sözleşmeyi kazanan şirket |
| Tutar | Sözleşmenin bedeli |
| Görev | Satın alınan şey (koda göre sınıflandırılır) |
| Tarih | Sözleşmenin verildiği zaman |
