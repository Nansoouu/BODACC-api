# 📖 Перекладач

**Його робота**: прочитати кожне офіційне оголошення й перетворити його на
ясну, зрозумілу картку: назву компанії, її адресу, діяльність, керівників,
суми, дати...

Офіційне оголошення — це адміністративний текст, часто довгий і
складний. Перекладач перетворює його на картку, яку може прочитати
кожен — семирічна дитина чи банкір.

## Що він робить

1. Він читає кожне оголошення від початку до кінця.
2. Він виокремлює важливу інформацію: хто, що, де, коли, скільки.
3. Він розміщує результат у картці відповідної компанії.
