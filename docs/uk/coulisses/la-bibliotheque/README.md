# 📚 Бібліотека контрактів

**Його робота**: розкладати в нашій бібліотеці французькі **державні
контракти** — договори, укладені адміністраціями, місцевими органами
влади та державними підприємствами.

Кожен контракт архівується з важливою інформацією: хто купує, хто
постачає, на яку суму, для якої місії.

**Сьогодні: понад мільйон контрактів, з 2015 року до наших днів.**

## Що містить бібліотека

| Інформація | Деталі |
|---|---|
| Хто купує | Місцевий орган влади чи адміністрація |
| Хто постачає | Компанія, яка виграла контракт |
| Сума | Ціна контракту |
| Місія | Що було куплено (класифіковано за кодом) |
| Дата | Коли контракт було укладено |
