# 🌅 Ранковий листоноша

**Його робота**: щоранку, дуже рано, зібрати всі офіційні оголошення
французьких компаній, опубліковані напередодні, і принести їх додому — не
втративши жодного.

Він — **перший крок** нашої історії: без нього ніщо не змогло б
потрапити на ваш екран.

## Що він робить щодня

1. Він вирушає по офіційні оголошення (створення, зміни, виключення з
   реєстру, процедури, продажі, подання звітності...).
2. Він приносить їх і акуратно розкладає в бібліотеці.
3. Він попереджає перекладача: "є робота!"
