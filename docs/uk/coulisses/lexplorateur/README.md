# 🧭 Дослідник

**Його робота**: коли листоноша, перекладач, дослідниця і бібліотекар
зроблять свою справу, дослідник відчиняє двері. Він перетворює зібрані дані
на **сторінки, статистику та зведення**, які може переглядати кожен — без
потреби бути експертом.

Він — **останній крок** нашої історії: той, хто доносить дані до вашого
екрана.

## Що він робить щодня

1. Він розкладає оголошення за темами (створення, зміни, припинення,
   продажі, здавання звітності...), щоб легко було орієнтуватися.
2. Він готує **лічильники в реальному часі** і підсумок дня: скільки
   оголошень надійшло, яка родина найчисленніша.
3. Він відчиняє двері бібліотеки для публіки: картки компаній, людей,
   регіонів та підсумок дня.
