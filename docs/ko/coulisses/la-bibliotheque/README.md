# 📚 계약 도서관

**그의 일**：프랑스의 **공공조달** — 행정기관, 지방자치단체, 공기업이 체결하는 계약 — 을 우리 도서관에 정리하는 것.

각 계약은 중요한 정보와 함께 보관됩니다：누가 사는지, 누가 공급하는지, 얼마에, 어떤 임무인지.

**현재：2015년부터 지금까지 100만 건이 넘는 계약.**

## 도서관에 담긴 것

| 정보 | 세부 |
|---|---|
| 누가 사는가 | 지방자치단체 또는 행정기관 |
| 누가 공급하는가 | 계약을 따낸 기업 |
| 금액 | 계약 가격 |
| 임무 | 구매된 것（코드로 분류） |
| 날짜 | 계약이 체결된 시기 |
