# 📚 계약 도서관

**일**：프랑스의 **공공 조달** — 행정 기관, 지방 자치 단체, 공기업이 체결한 계약 — 을 도서관에 정리하는 일.

각 계약은 중요한 정보와 함께 보관됩니다：누가 사는지, 누가 공급하는지, 얼마인지, 어떤 임무인지.

**현재：2015년부터 현재까지 100만 건 이상의 계약.**

## 도서관에 있는 것

| 정보 | 세부 사항 |
|---|---|
| 누가 구매 | 지방 자치 단체 또는 행정 기관 |
| 누가 공급 | 계약을 따낸 회사 |
| 금액 | 계약 가격 |
| 임무 | 구매한 것(코드로 분류) |
| 날짜 | 계약이 체결된 시기 |
