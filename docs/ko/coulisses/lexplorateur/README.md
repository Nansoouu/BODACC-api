# 🧭 탐험가

**그의 일**：우편배달부, 번역가, 조사관, 그리고 사서가 각자의 일을 마친 후, 탐험가가 문을 엽니다. 수집된 데이터를 전문가가 아니어도 누구나 볼 수 있는 **뷰, 통계, 요약**으로 바꿉니다.

그는 우리 이야기의 **마지막 단계**입니다：데이터를 여러분의 화면까지 가져오는 사람입니다.

## 그가 매일 하는 일

1. 공고를 주제별로 정리합니다（설립, 변경, 말소, 매각, 결산서 제출…）. 쉽게 찾을 수 있도록 하기 위해서입니다.
2. **실시간 카운터**와 오늘의 요약을 준비합니다：공고가 몇 건 도착했는지, 어떤 유형이 가장 많은지.
3. 도서관의 문을 일반에 엽니다：기업 카드, 인물, 지역, 그리고 오늘의 요약.
