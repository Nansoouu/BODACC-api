# 🌅 아침의 우편배달부

**그의 일**：매일 아침, 매우 이른 시간에 전날 게재된 프랑스 기업의 공식 공고를 모두 수집해, 하나도 잃지 않고 집으로 가져오는 것.

그는 우리 이야기의 **첫 번째 단계**입니다：그가 없으면 아무것도 여러분의 화면에 도달할 수 없습니다.

## 그가 매일 하는 일

1. 공식 공고를 가지러 갑니다（설립, 변경, 말소, 절차, 매각, 결산서 제출…）.
2. 가져와 도서관에 조심스럽게 정리합니다.
3. 번역가에게 알립니다：「일거리가 생겼어!」
