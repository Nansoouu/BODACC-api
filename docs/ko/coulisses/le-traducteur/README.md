**일**：각 공식 공고를 읽고 명확하고 이해하기 쉬운 카드로 변환하는 일：회사 이름, 주소, 활동, 대표, 금액, 날짜...

공식 공고는 행정 문서로, 길고 복잡한 경우가 많습니다. 번역가는 그것을 누구나 읽을 수 있는 카드로 만듭니다 — 7살 아이도, 은행원도.

## 하는 일

1. 각 공고를 처음부터 끝까지 읽습니다.
2. 중요한 정보를 추출합니다：누가, 무엇을, 어디서, 언제, 얼마.
3. 결과를 해당 회사의 카드에 정리합니다.
