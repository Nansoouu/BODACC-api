**그의 일**：모든 공식 공고를 읽고 명확하고 이해하기 쉬운 카드로 바꾸는 것：기업명, 주소, 사업 내용, 임원, 금액, 날짜….

## 그가 하는 일

1. 각 공고를 처음부터 끝까지 읽습니다.
2. 중요한 정보를 뽑아냅니다：누가, 무엇을, 어디서, 언제, 얼마나.
3. 결과를 해당 기업의 카드에 정리합니다.
