# 📚 مكتبة العقود

**مهنته**: ترتيب **الصفقات العامة** لفرنسا في مكتبتنا — العقود التي تبرمها الإدارات والجماعات المحلية والشركات العامة.

كل عقد يُحفظ مع المعلومات المهمة: من يشتري، من يورّد، بأي مبلغ، لأي مهمة.

**اليوم: أكثر من مليون عقد، من 2015 حتى اليوم.**

## ما تحتويه المكتبة

| المعلومة | التفاصيل |
|---|---|
| من يشتري | الجماعة المحلية أو الإدارة |
| من يورّد | الشركة التي فازت بالعقد |
| المبلغ | ثمن العقد |
| المهمة | ما تم شراؤه (مصنف حسب الرمز) |
| التاريخ | متى تم إسناد العقد |
