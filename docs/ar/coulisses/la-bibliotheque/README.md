# 📚 مكتبة العقود

**مهنته**: ترتيب **الصفقات العمومية** الفرنسية في مكتبتنا — العقود التي تبرمها الإدارات والجماعات المحلية والمؤسسات العمومية.

كل عقد مؤرشَف مع المعلومات المهمة: من يشتري، من يورّد، بأي مبلغ، لأي مهمة.

**اليوم: أكثر من مليون عقد، من 2015 حتى اليوم.**

## ما تحتويه المكتبة

| المعلومة | التفاصيل |
|---|---|
| من يشتري | الجماعة المحلية أو الإدارة |
| من يورّد | الشركة التي فازت بالعقد |
| المبلغ | ثمن العقد |
| المهمة | ما تم شراؤه (مصنّف حسب الكود) |
| التاريخ | متى أُسند العقد |
