# 🔍 المحققة

**مهنتها**: تكميل بطاقة كل شركة بمعلوماتها **العامة** — موقعها الإلكتروني، هاتفها، شبكاتها الاجتماعية.

لا تبحث إلا عما تعرضه الشركة نفسها للعموم. لا شيء خاص، لا شيء سري، لا شيء خلف كلمة مرور.

## ما تضيفه إلى البطاقة

| المعلومة | مصدرها |
|---|---|
| الموقع الإلكتروني | ما تعرضه الشركة علناً |
| الهاتف | رقم عام |
| الشبكات الاجتماعية | روابط عامة (LinkedIn، Instagram...) |
| الوجود على الخريطة | يتحقق منه الجغرافي |
| صفات المسيّرين | سجلات رسمية عامة («رئيس SAS»، «مدير»...) |
