# 🔍 المحققة

**مهنتها**: إكمال بطاقة كل شركة بمعلوماتها **العامة** — موقعها الإلكتروني، هاتفها، شبكاتها الاجتماعية.

إنها تبحث فقط عما تعرضه الشركة بنفسها للجمهور العام. لا شيء خاص، لا شيء سري، لا شيء خلف كلمة مرور.

## ما تضيفه إلى البطاقة

| المعلومة | مصدرها |
|---|---|
| الموقع الإلكتروني | ما تعرضه الشركة علنًا |
| الهاتف | رقم عام |
| الشبكات الاجتماعية | روابط عامة (LinkedIn، Instagram...) |
| الحضور على الخريطة | تم التحقق منه بواسطة الجغرافي |
| صفات المدراء | السجلات العامة الرسمية («رئيس SAS»، «مدير»...) |
