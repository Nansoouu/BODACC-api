# 📖 المترجم

**مهنته**: قراءة كل إعلان رسمي وتحويله إلى بطاقة واضحة ومفهومة: اسم الشركة، عنوانها، نشاطها، مدراؤها، المبالغ، التواريخ...

الإعلان الرسمي نص إداري، غالبًا ما يكون طويلًا ومعقدًا. يحوّله المترجم إلى بطاقة يمكن للجميع قراءتها — طفل في السابعة من عمره أو مصرفي.

## ما يفعله

1. يقرأ كل إعلان من بدايته إلى نهايته.
2. يستخرج المعلومات المهمة: من، ماذا، أين، متى، كم.
3. يرتب النتيجة في بطاقة الشركة المعنية.
