# 🧭 المستكشف

**مهنته**: بعد أن يؤدي ساعي البريد والمترجم والمحققة وأمين المكتبة عملهم، يفتح المستكشف الأبواب. يحوّل البيانات المجمّعة إلى **عروض وإحصاءات وملخصات** يمكن للجميع الاطلاع عليها، دون أن يكونوا خبراء.

إنه **الخطوة الأخيرة** في قصتنا: الشخص الذي يوصِل البيانات إلى شاشتك.

## ما يفعله كل يوم

1. يرتّب الإعلانات حسب الموضوع (إنشاءات، تعديلات، شطب، بيع، إيداع الحسابات...) لتسهيل العثور عليها.
2. يجهّز **العدادات المباشرة** وملخص اليوم: كم إعلاناً وصل، وأي فئة هي الأكثر عدداً.
3. يفتح أبواب المكتبة أمام الجمهور: بطاقات الشركات، الأشخاص، المناطق، وملخص اليوم.

## وعوده

| الوعد | التفاصيل |
|---|---|
| محدّث دائماً | العدادات تعكس العمل الحقيقي لليوم |
| سهل الاطلاع | لا مصطلحات: مواضيع، فلاتر، بطاقات واضحة |
| قابل للتحقق | كل رقم يأتي من الإعلانات الرسمية |
