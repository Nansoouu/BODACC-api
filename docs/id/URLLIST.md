# BODACC.io : daftar URL

Titik masuk situs : dipelihara untuk crawler, bot, dan agen.
Semua URL di bawah mengembalikan HTTP 200 dan dapat diakses publik.

## Situs (multibahasa : 20 bahasa, /id default)

- Beranda: https://bodacc.io/id
- Pengumuman: https://bodacc.io/id/annonces
- Perusahaan: https://bodacc.io/id/entreprises
- Orang: https://bodacc.io/id/personnes
- Aktor (kurator): https://bodacc.io/id/acteurs
- Harga: https://bodacc.io/id/tarifs
- Teknologi / data terbuka: https://bodacc.io/id/technologie
- Hub wilayah: https://bodacc.io/id/regions
- Kota: https://bodacc.io/id/villes

## Penemuan & feed

- RSS feed (daily recaps + latest notices): https://bodacc.io/rss.xml
- Sitemap index: https://bodacc.io/sitemap.xml
- robots.txt: https://bodacc.io/robots.txt
- llms.txt (for AI agents): https://bodacc.io/llms.txt
- ads.txt: https://bodacc.io/ads.txt
- OpenAPI spec: https://bodacc.io/api/bodacc/openapi.json
