# 🗺️ Ahli Geografi

**Pekerjaannya**: memeriksa bahwa setiap perusahaan benar-benar ada di peta
dunia (Google Maps) dan mencatat apa yang kita lihat di sana: alamat,
kategori, peringkat, jumlah ulasan, situs web, telepon.

Berkat dia, kartu perusahaan juga menunjukkan **kehadiran nyata**-nya dalam
kehidupan sehari-hari, bukan hanya dokumen resminya.

## Yang ia catat

| Informasi | Detail |
|---|---|
| Alamat di peta | Di mana perusahaan sebenarnya berada |
| Kategori | Restoran, perdagangan, jasa... |
| Peringkat dan ulasan | Apa yang pelanggan katakan secara publik |
| Situs web / telepon | Diverifikasi di kartu publik |

## Janji-janjinya

| Janji | Detail |
