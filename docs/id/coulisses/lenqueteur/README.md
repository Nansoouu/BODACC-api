# 🔍 Peneliti

**Pekerjaannya**: melengkapi kartu setiap perusahaan dengan informasi
**publik**-nya — situs web, telepon, media sosial.

Ia hanya mencari apa yang perusahaan tunjukkan sendiri kepada publik.
Tidak ada yang privat, tidak ada yang rahasia, tidak ada yang berada di
balik kata sandi.

## Yang ia tambahkan ke kartu

| Informasi | Asalnya dari mana |
|---|---|
| Situs web | Apa yang perusahaan tampilkan secara publik |
| Telepon | Nomor publik |
| Media sosial | Tautan publik (LinkedIn, Instagram...) |
| Kehadiran di peta | Diverifikasi oleh ahli geografi |
| Kualifikasi direktur | Register publik resmi ("Presiden SAS", "Pengelola"...) |

## Janji-janjinya

| Janji | Detail |
|---|---|
| Hanya publik | Tidak pernah data privat atau terlindungi |
| Bertahap | Kartu semakin kaya seiring waktu |
| Dapat diverifikasi | Setiap data ditampilkan dengan sumbernya |
