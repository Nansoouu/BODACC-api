# 🧭 Der Entdecker

**Sein Beruf**: Sobald der Postbote, der Übersetzer, die Ermittlerin und der
Bibliothekar ihre Arbeit erledigt haben, öffnet der Entdecker die Türen. Er
verwandelt die gesammelten Daten in **Ansichten, Statistiken und
Zusammenfassungen**, die jeder ohne Fachkenntnisse einsehen kann.

Er ist der **letzte Schritt** unserer Geschichte: derjenige, der die Daten auf
deinen Bildschirm bringt.

## Was er jeden Tag tut

1. Er ordnet die Bekanntmachungen nach Thema (Gründungen, Änderungen,
   Löschungen, Verkäufe, Einreichungen von Jahresabschlüssen...), damit man
   sich leicht zurechtfindet.
2. Er bereitet die **Live-Zähler** und die Tageszusammenfassung vor: wie viele
   Bekanntmachungen eingetroffen sind, welche Familie am häufigsten vorkommt.
3. Er öffnet die Türen der Bibliothek für die Öffentlichkeit:
   Unternehmenseinträge, Personen, Regionen und die Tagesübersicht.
