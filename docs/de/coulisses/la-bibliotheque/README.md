# 📚 Die Vertragsbibliothek

**Sein Beruf**: in unserer Bibliothek die **öffentlichen Aufträge**
Frankreichs archivieren — die Verträge, die von Verwaltungen, Gebietskörperschaften
und öffentlichen Unternehmen geschlossen werden.

Jeder Vertrag wird mit den wichtigen Informationen archiviert: wer kauft,
wer liefert, für welchen Betrag, für welchen Auftrag.

**Heute: mehr als eine Million Verträge, von 2015 bis heute.**

## Was die Bibliothek enthält

| Information | Detail |
|---|---|
| Wer kauft | Die Gebietskörperschaft oder die Verwaltung |
| Wer liefert | Das Unternehmen, das den Auftrag gewonnen hat |
| Betrag | Der Preis des Vertrags |
| Auftrag | Was gekauft wurde (nach Code klassifiziert) |
| Datum | Wann der Vertrag vergeben wurde |
