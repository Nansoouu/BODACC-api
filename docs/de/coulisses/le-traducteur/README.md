# 📖 Der Übersetzer

**Sein Beruf**: jede offizielle Bekanntmachung lesen und in einen klaren,
verständlichen Eintrag verwandeln: den Namen des Unternehmens, seine Adresse,
seine Tätigkeit, seine Geschäftsführung, die Beträge, die Daten...

Eine offizielle Bekanntmachung ist ein Verwaltungstext, oft lang und kompliziert.
Der Übersetzer macht daraus einen Eintrag, den jeder lesen kann — ein 7-jähriges
Kind ebenso wie ein Banker.

## Was er tut

1. Er liest jede Bekanntmachung vollständig.
2. Er zieht die wichtigen Informationen heraus: wer, was, wo, wann, wie viel.
3. Er ordnet das Ergebnis im Eintrag des betreffenden Unternehmens ein.

## Die Arten von Bekanntmachungen, die er lesen kann

| Art | Was man erfährt | Bisher gelesene Beispiele |
|---|---|---|
| Einreichungen von Jahresabschlüssen | Die eingereichten Jahresabschlüsse, pünktlich oder verspätet | ~9 Millionen |
| Änderungen | Wechsel der Geschäftsführung, Kapital, Übertragungen | ~2,6 Millionen |
| Gründungen | Geburt des Unternehmens: Kapital, Adresse, Gründer | ~2,4 Millionen |
| Löschungen | Ende der Tätigkeit, Lebensdauer des Unternehmens | ~1,6 Millionen |
| Insolvenzverfahren | Schutzschirm, Sanierung, Liquidation | ~820 000 |
| Verkäufe und Abtretungen | Verkauf eines Geschäfts: Preis, Verkäufer, Käufer | ~230 000 |
| Registrierungen | Eintragung ins Register, Registerwechsel | ~213 000 |
| Vergleiche | Gütliche Einigungen | ~1 000 |
| Wiederaufnahmen | Rückkehr zur Tätigkeit | ~680 |
| Verschiedenes | Pfändungen, Nichtigkeiten | einige |

**Insgesamt: jede Bekanntmachung, die seit 2004 je veröffentlicht wurde, wurde gelesen und einsortiert.**
