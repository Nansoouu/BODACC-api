# 🔍 Die Ermittlerin

**Ihr Beruf**: den Eintrag jedes Unternehmens mit seinen **öffentlichen**
Informationen vervollständigen — seiner Website, seiner Telefonnummer,
seinen sozialen Netzwerken.

Sie sucht nur das, was das Unternehmen selbst der Öffentlichkeit zeigt.
Nichts Privates, nichts Geheimes, nichts hinter einem Passwort.

## Was sie zum Eintrag hinzufügt

| Information | Woher sie stammt |
|---|---|
| Website | Was das Unternehmen öffentlich zeigt |
| Telefonnummer | Öffentliche Nummer |
| Soziale Netzwerke | Öffentliche Links (LinkedIn, Instagram...) |
| Präsenz auf der Karte | Vom Geografen überprüft |
| Qualifikationen der Geschäftsführung | Offizielle öffentliche Register („Präsident der SAS“, „Geschäftsführer“...) |

## Ihre Versprechen

| Versprechen | Detail |
