# 🌅 Der Postbote am Morgen

**Sein Beruf**: jeden Morgen, sehr früh, alle offiziellen Bekanntmachungen
französischer Unternehmen vom Vortag einsammeln und nach Hause
bringen, ohne auch nur eine zu verlieren.

Er ist der **erste Schritt** unserer Geschichte: Ohne ihn könnte nichts
auf Ihren Bildschirm gelangen.

## Was er jeden Tag tut

1. Er holt die offiziellen Bekanntmachungen (Gründungen, Änderungen,
   Löschungen, Verfahren, Verkäufe, Einreichungen von Jahresabschlüssen...).
2. Er bringt sie zurück und ordnet sie sorgfältig in der Bibliothek ein.
3. Er warnt den Übersetzer: „Es gibt Arbeit!“
