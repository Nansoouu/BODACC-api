# 🧩 Das Personen-Puzzle

**Sein Beruf**: jede Person finden, die in den Bekanntmachungen erscheint —
Geschäftsführer, Liquidatoren, Abschlussprüfer, Käufer, Verkäufer — und sie
mit ihren Unternehmen verbinden.

Dank ihm können wir einfache Fragen beantworten:
- „Welche Unternehmen führt diese Person?“
- „Wer steckt hinter dieser Gesellschaft?“
- „Seit wann?“

## Wie er arbeitet

1. Er liest jede Bekanntmachung und findet die genannten Personen.
2. Er prüft, ob die Person bereits existiert (gleicher Name, gleicher Vorname).
3. Er verbindet sie mit dem Unternehmen und der Funktion (Präsident, Geschäftsführer...).
4. Er vervollständigt den Eintrag mit den offiziellen Qualifikationen.
