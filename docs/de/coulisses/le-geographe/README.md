# 🗺️ Der Geograf

**Sein Beruf**: prüfen, ob jedes Unternehmen wirklich auf der Weltkarte
(Google Maps) existiert, und notieren, was man dort sieht: die Adresse, die
Kategorie, die Bewertung, die Anzahl der Rezensionen, die Website, die
Telefonnummer.

Dank ihm zeigt ein Unternehmenseintrag auch seine **reale Präsenz** im
echten Leben, nicht nur seine offiziellen Papiere.

## Was er notiert

| Information | Detail |
|---|---|
| Adresse auf der Karte | Wo das Unternehmen wirklich ist |
| Kategorie | Gastronomie, Handel, Dienstleistungen... |
| Bewertung und Rezensionen | Was Kunden öffentlich sagen |
| Website / Telefon | Auf dem öffentlichen Eintrag überprüft |
