# 🌅 Poranny listonosz

**Jego zawód**: każdego ranka, bardzo wcześnie, zebrać wszystkie oficjalne
ogłoszenia francuskich firm opublikowane poprzedniego dnia i przynieść je do
domu — nie gubiąc ani jednego.

To **pierwszy krok** naszej historii: bez niego nic nie mogłoby trafić na
Twój ekran.

## Co robi każdego dnia

1. Wyrusza po oficjalne ogłoszenia (zakładanie firm, zmiany, wykreślenia,
   postępowania, sprzedaże, składanie sprawozdań finansowych...).
2. Przynosi je i starannie układa w bibliotece.
3. Ostrzega tłumacza: "jest praca!"
