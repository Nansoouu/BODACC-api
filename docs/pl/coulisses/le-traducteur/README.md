# 📖 Tłumacz

**Jego zawód**: przeczytać każde oficjalne ogłoszenie i zamienić je w jasną,
zrozumiałą kartę: nazwę firmy, jej adres, działalność, osoby zarządzające,
kwoty, daty...

Oficjalne ogłoszenie to tekst administracyjny, często długi i skomplikowany.
Tłumacz zamienia go w kartę, którą każdy może przeczytać — 7-letnie dziecko
albo bankier.

## Co robi

1. Czyta każde ogłoszenie od początku do końca.
2. Wyciąga z niego ważne informacje: kto, co, gdzie, kiedy, za ile.
3. Umieszcza wynik w karcie danej firmy.

## Rodzaje ogłoszeń, które potrafi czytać

| Rodzaj | Czego się dowiadujemy | Przeczytane dotąd |
|---|---|---|
| Składanie sprawozdań finansowych | Złożone roczne sprawozdania, w terminie lub z opóźnieniem | ~9 milionów |
| Zmiany | Zmiany członków zarządu, kapitału, przeniesienia | ~2,6 miliona |
| Zakładanie firm | Narodziny firmy: kapitał, adres, założyciele | ~2,4 miliona |
| Wykreślenia | Koniec działalności, czas życia firmy | ~1,6 miliona |
| Postępowania upadłościowe | Ochrona, restrukturyzacja, likwidacja | ~820 000 |
| Sprzedaże i zbycia | Sprzedaż przedsiębiorstwa: cena, sprzedawca, kupujący | ~230 000 |
| Rejestracje | Wpis do rejestru, przeniesienia rejestrów | ~213 000 |
| Ugody | Porozumienia polubowne | ~1 000 |
| Przywrócenia | Powrót do działalności | ~680 |
| Różne | Zajęcia, stwierdzenia nieważności | kilka |

**W sumie: każde ogłoszenie opublikowane od 2004 roku zostało przeczytane i uporządkowane.**
