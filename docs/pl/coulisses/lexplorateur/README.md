# 🧭 Odkrywca

**Jego praca**: kiedy listonosz, tłumacz, śledcza i bibliotekarz zrobią swoje,
odkrywca otwiera drzwi. Przekształca zebrane dane w **widoki, statystyki i
podsumowania**, które każdy może przeglądać — bez bycia ekspertem.

Jest **ostatnim krokiem** naszej historii: tym, który dostarcza dane na Twój
ekran.

## Co robi każdego dnia

1. Porządkuje ogłoszenia według tematu (utworzenia, zmiany, wykreślenia,
   sprzedaże, złożenia sprawozdań finansowych...), żeby łatwo było się w nich
   odnaleźć.
2. Przygotowuje **liczniki na żywo** i podsumowanie dnia: ile ogłoszeń
   wpłynęło, która rodzina jest najliczniejsza.
3. Otwiera drzwi biblioteki dla publiczności: karty firm, osoby, regiony oraz
   podsumowanie dnia.
