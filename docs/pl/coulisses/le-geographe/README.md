# 🗺️ Geograf

**Jego zawód**: sprawdzić, czy każda firma naprawdę istnieje na mapie świata
(Google Maps), i zanotować to, co tam widzimy: adres, kategorię, ocenę,
liczbę opinii, stronę internetową, telefon.

Dzięki niemu karta firmy pokazuje także jej **realną obecność** w prawdziwym
życiu, nie tylko oficjalne dokumenty.

## Co notuje

| Informacja | Szczegóły |
|---|---|
| Adres na mapie | Gdzie firma naprawdę się znajduje |
| Kategoria | Gastronomia, handel, usługi... |
| Ocena i opinie | Co klienci mówią publicznie |
| Strona internetowa / telefon | Zweryfikowane na karcie publicznej |

## Jego obietnice

| Obietnica | Szczegóły |
|---|---|
| Tylko publiczne | Wyłącznie to, co każdy może zobaczyć |
