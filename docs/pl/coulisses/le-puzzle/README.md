# 🧩 Układanka osób

**Jego zawód**: odnaleźć każdą osobę występującą w ogłoszeniach — członków
zarządu, likwidatorów, biegłych rewidentów, kupujących, sprzedających — i
połączyć ją z jej firmami.

Dzięki niemu możemy odpowiadać na proste pytania:
- "Którymi firmami kieruje ta osoba?"
- "Kto stoi za tą spółką?"
- "Od kiedy?"

## Jak pracuje

1. Czyta każde ogłoszenie i wyłapuje wymienione osoby.
2. Sprawdza, czy osoba już istnieje (to samo nazwisko, to samo imię).
3. Łączy ją z firmą i funkcją (prezes, zarządca...).
4. Uzupełnia kartę o oficjalne funkcje.
