# 📚 Biblioteka kontraktów

**Jego zawód**: umieszczać w naszej bibliotece francuskie **zamówienia
publiczne** — kontrakty zawierane przez administracje, samorządy i
przedsiębiorstwa publiczne.

Każdy kontrakt jest archiwizowany z ważnymi informacjami: kto kupuje, kto
dostarcza, za jaką kwotę i w jakiej sprawie.

**Dziś: ponad milion kontraktów, od 2015 roku do dziś.**

## Co zawiera biblioteka

| Informacja | Szczegóły |
|---|---|
| Kto kupuje | Samorząd lub administracja |
| Kto dostarcza | Firma, która wygrała kontrakt |
| Kwota | Cena kontraktu |
| Przedmiot | To, co kupiono (sklasyfikowane według kodu) |
| Data | Kiedy przyznano kontrakt |

## Jego obietnice
