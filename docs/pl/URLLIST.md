# BODACC.io : lista URL

Punkty wejścia serwisu : utrzymywane dla robotów i agentów.
Wszystkie poniższe adresy URL zwracają HTTP 200 i są publicznie dostępne.

## Serwis (wielojęzyczny : 20 języków, domyślnie /pl)

- Strona główna: https://bodacc.io/pl
- Ogłoszenia: https://bodacc.io/pl/annonces
- Firmy: https://bodacc.io/pl/entreprises
- Osoby: https://bodacc.io/pl/personnes
- Aktorzy (syndycy): https://bodacc.io/pl/acteurs
- Cennik: https://bodacc.io/pl/tarifs
- Technologia / otwarte dane: https://bodacc.io/pl/technologie
- Hub regionów: https://bodacc.io/pl/regions
- Miasta: https://bodacc.io/pl/villes

## Odkrywanie i kanały

- RSS feed (daily recaps + latest notices): https://bodacc.io/rss.xml
- Sitemap index: https://bodacc.io/sitemap.xml
- robots.txt: https://bodacc.io/robots.txt
- llms.txt (for AI agents): https://bodacc.io/llms.txt
- ads.txt: https://bodacc.io/ads.txt
- OpenAPI spec: https://bodacc.io/api/bodacc/openapi.json

- Notice detail: https://bodacc.io/api/bodacc/annonces/A202601511039

- People: https://bodacc.io/api/bodacc/personnes/397362
- Live counters: https://bodacc.io/api/bodacc/stats/counts
- Daily stats: https://bodacc.io/api/bodacc/stats/daily
- NAF reference: https://bodacc.io/api/bodacc/naf
