# 🔍 L'enquêteur

**Son métier** : compléter la fiche de chaque entreprise avec ses informations
**publiques** — son site web, son téléphone, ses réseaux sociaux.

Il ne cherche que ce que l'entreprise montre elle-même au grand public.
Rien de privé, rien de secret, rien qui ne soit derrière un mot de passe.
