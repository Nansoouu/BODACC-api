# 🗺️ Le géographe

**Son métier** : vérifier que chaque entreprise existe bien sur la carte du
monde (Google Maps) et noter ce qu'on y voit : l'adresse, la catégorie, la
note, le nombre d'avis, le site web, le téléphone.

Grâce à lui, une fiche d'entreprise montre aussi sa **présence réelle** dans la
vraie vie, pas seulement ses papiers officiels.

## Ce qu'il note

| Information | Détail |
|---|---|
| Adresse sur la carte | Où l'entreprise se trouve vraiment |
| Catégorie | Restauration, commerce, services... |
| Note et avis | Ce que les clients disent publiquement |
| Site web / téléphone | Vérifiés sur la fiche publique |
