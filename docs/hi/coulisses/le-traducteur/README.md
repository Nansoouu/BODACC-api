# 📖 अनुवादक

**उसका काम**: हर आधिकारिक घोषणा को पढ़ना और उसे स्पष्ट, समझने योग्य कार्ड में बदलना: कंपनी का नाम, उसका पता, उसकी गतिविधि, उसके निदेशक, राशियाँ, तारीखें...

आधिकारिक घोषणा एक प्रशासनिक पाठ है, जो अक्सर लंबा और जटिल होता है। अनुवादक उसे ऐसे कार्ड में बदल देता है जिसे हर कोई पढ़ सके — 7 साल का बच्चा या बैंकर।

## वह क्या करता है

1. वह हर घोषणा को शुरू से अंत तक पढ़ता है।
2. वह महत्वपूर्ण जानकारी निकालता है: कौन, क्या, कहाँ, कब, कितना।
3. वह परिणाम को संबंधित कंपनी के कार्ड में व्यवस्थित करता है।
