# 📚 अनुबंध पुस्तकालय

**उसका पेशा**: फ्रांस के **सार्वजनिक खरीद** अनुबंधों को हमारे पुस्तकालय में व्यवस्थित करना — प्रशासनों, स्थानीय निकायों और सार्वजनिक कंपनियों द्वारा किए गए अनुबंध।

हर अनुबंध महत्वपूर्ण जानकारी के साथ संग्रहीत है: कौन खरीदता है, कौन आपूर्ति करता है, किस राशि के लिए, किस मिशन के लिए।

**आज: 2015 से अब तक दस लाख से अधिक अनुबंध।**

## पुस्तकालय में क्या है

| जानकारी | विवरण |
|---|---|
| कौन खरीदता है | स्थानीय निकाय या प्रशासन |
| कौन आपूर्ति करता है | वह कंपनी जिसने अनुबंध जीता |
| राशि | अनुबंध की कीमत |
| मिशन | क्या खरीदा गया (कोड द्वारा वर्गीकृत) |
| तिथि | अनुबंध कब प्रदान किया गया |

## उसके वादे

| वादा | विवरण |
|---|---|
| पूर्ण | 2015 से, हर दिन अद्यतन |
| सार्वजनिक | स्वतंत्र रूप से और निःशुल्क देखने योग्य |
| जुड़ा हुआ | संभव होने पर अनुबंध कंपनियों से जुड़े होते हैं |
