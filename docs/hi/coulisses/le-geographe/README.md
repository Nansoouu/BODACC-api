# 🗺️ भूगोलवेत्ता

**उसका पेशा**: जाँच करना कि हर कंपनी वास्तव में विश्व मानचित्र (Google Maps) पर मौजूद है, और वहाँ जो दिखता है उसे नोट करना: पता, श्रेणी, रेटिंग, समीक्षाओं की संख्या, वेबसाइट, फ़ोन नंबर।

उसकी बदौलत, एक कंपनी कार्ड अपनी **वास्तविक उपस्थिति** भी दिखाता है — केवल आधिकारिक कागजात ही नहीं।

## वह क्या नोट करता है

| जानकारी | विवरण |
|---|---|
| नक्शे पर पता | कंपनी वास्तव में कहाँ है |
| श्रेणी | रेस्तरां, वाणिज्य, सेवाएँ... |
| रेटिंग और समीक्षाएँ | ग्राहक सार्वजनिक रूप से क्या कहते हैं |
| वेबसाइट / फ़ोन | सार्वजनिक कार्ड पर सत्यापित |
