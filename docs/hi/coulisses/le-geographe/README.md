# 🗺️ भूगोलवेत्ता

**उसका काम**: जाँच करना कि हर कंपनी वास्तव में विश्व मानचित्र (Google Maps) पर मौजूद है और वहाँ जो दिखता है उसे नोट करना: पता, श्रेणी, रेटिंग, समीक्षाओं की संख्या, वेबसाइट, फोन नंबर।

उसकी बदौलत, कंपनी कार्ड वास्तविक दुनिया में उसकी **वास्तविक उपस्थिति** भी दिखाता है, न कि केवल उसके आधिकारिक कागजात।

## वह क्या नोट करता है

| जानकारी | विवरण |
|---|---|
| नक्शे पर पता | कंपनी वास्तव में कहाँ है |
| श्रेणी | रेस्तरां, दुकानें, सेवाएँ... |
| रेटिंग और समीक्षाएँ | ग्राहक सार्वजनिक रूप से क्या कहते हैं |
| वेबसाइट / फोन | सार्वजनिक कार्ड पर सत्यापित |
