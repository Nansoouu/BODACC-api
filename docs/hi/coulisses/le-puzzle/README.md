# 🧩 लोगों की पहेली

**उसका काम**: घोषणाओं में दिखने वाले हर व्यक्ति को खोजना — निदेशक, परिसमापक, लेखा परीक्षक, खरीदार, विक्रेता — और उन्हें उनकी कंपनियों से जोड़ना।

उसकी बदौलत, हम सरल प्रश्नों के उत्तर दे सकते हैं:
- «यह व्यक्ति किन कंपनियों का नेतृत्व करता है?»
- «इस कंपनी के पीछे कौन है?»
- «कब से?»

## वह कैसे काम करता है

1. वह हर घोषणा पढ़ता है और उल्लिखित लोगों को पहचानता है।
2. वह जाँचता है कि व्यक्ति पहले से मौजूद है या नहीं (समान नाम, समान उपनाम)।
3. वह उन्हें कंपनी और पद (अध्यक्ष, प्रबंधक...) से जोड़ता है।
4. वह कार्ड को आधिकारिक योग्यताओं से पूरा करता है।
