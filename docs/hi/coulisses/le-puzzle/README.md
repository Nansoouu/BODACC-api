# 🧩 लोगों की पहेली

**उसका पेशा**: घोषणाओं में आने वाले हर व्यक्ति को ढूँढना — निदेशक, परिसमापक, लेखा परीक्षक, क्रेता, विक्रेता — और उसे उसकी कंपनियों से जोड़ना।

उसकी बदौलत, हम सरल प्रश्नों का उत्तर दे सकते हैं:
- «यह व्यक्ति किन कंपनियों का नेतृत्व करता है?»
- «इस कंपनी के पीछे कौन है?»
- «कब से?»

## वह कैसे काम करता है

1. वह हर घोषणा पढ़ता है और उल्लिखित लोगों को पहचानता है।
2. वह जाँचता है कि व्यक्ति पहले से मौजूद है या नहीं (वही नाम, वही उपनाम)।
3. वह उसे कंपनी और पद (अध्यक्ष, प्रबंधक...) से जोड़ता है।
4. वह कार्ड को आधिकारिक उपाधियों से पूरा करता है।
