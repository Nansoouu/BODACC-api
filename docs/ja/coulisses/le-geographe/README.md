# 🗺️ 地理学者

**彼の仕事**：各企業が世界地図（Google Maps）上に本当に存在するかを確認し、そこに見えるものを記録すること：住所、カテゴリ、評価、レビュー数、ウェブサイト、電話番号。

彼のおかげで、企業カードには公式書類だけでなく、現実世界での**実際の存在**も表示されます。

## 彼が記録するもの

| 情報 | 詳細 |
|---|---|
| 地図上の住所 | 企業が実際にある場所 |
| カテゴリ | 飲食、小売、サービス… |
| 評価とレビュー | 顧客が公に述べていること |
| ウェブサイト / 電話番号 | 公開カードで確認済み |
