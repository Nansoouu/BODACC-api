# 🗺️ 地理学者

**仕事**：各企業が世界地図（Google Maps）上に本当に存在するかを確認し、見えるものを記録すること：住所、カテゴリ、評価、口コミ数、ウェブサイト、電話番号。

彼のおかげで、企業カードには公式書類だけでなく、現実世界での**実際の存在**も表示されます。

## 記録するもの

| 情報 | 詳細 |
|---|---|
| 地図上の住所 | 企業が実際にある場所 |
| カテゴリ | 飲食、小売、サービス... |
| 評価と口コミ | 顧客が公開している意見 |
| ウェブサイト / 電話番号 | 公開カードで確認済み |

## 彼の約束

| 約束 | 詳細 |
|---|---|
| 公開のみ | 誰もが見られるものだけ |
| キャンペーン単位 | 企業リストをグループごとに探索 |
| 丁寧に | 誰も邪魔しないようゆっくり進む |
