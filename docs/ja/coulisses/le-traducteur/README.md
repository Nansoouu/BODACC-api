# 📖 翻訳者

**彼の仕事**：すべての公式公示を読み、明確でわかりやすいカードに変換すること：企業名、住所、事業内容、役員、金額、日付…。

公式公示は行政文書で、しばしば長く複雑です。翻訳者は、それを誰でも読めるカードにします — 7歳の子供でも、銀行家でも。

## 彼がすること

1. 各公示を最初から最後まで読みます。
2. 重要な情報を取り出します：誰が、何を、どこで、いつ、いくら。
3. 結果を、対象企業のカードに整理します。

## 彼が読める公示の種類

| 種類 | わかること | これまでに読んだ数 |
|---|---|---|
| 決算書の提出 | 提出された年次決算、期限内か遅延か | 約900万件 |
| 変更 | 役員・資本の変更、移転 | 約260万件 |
| 設立 | 企業の誕生：資本、住所、創業者 | 約240万件 |
| 抹消 | 事業の終了、企業の存続期間 | 約160万件 |
| 集団的処理手続 | 保全、更生、清算 | 約820 000件 |
| 売却・譲渡 | 事業の売却：価格、売主、買主 | 約230 000件 |
| 登記 | 登録簿への記載、登記所の移管 | 約213 000件 |
| 調停 | 和解合意 | 約1 000件 |
| 復活 | 事業への復帰 | 約680件 |
| その他 | 差押え、無効 | 数件 |

**合計：2004年以降に公開されたすべての公示が読まれ、整理されています。**
