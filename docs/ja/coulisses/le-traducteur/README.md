# 📖 翻訳者

**仕事**：各公式公告を読み、明確でわかりやすいカードに変換すること：会社名、住所、活動内容、役員、金額、日付...

公式公告は行政文書で、長く複雑なことがよくあります。翻訳者はそれを、誰でも読めるカードにします — 7歳の子どもでも、銀行員でも。

## 仕事内容

1. 各公告を最初から最後まで読みます。
2. 重要な情報を取り出します：誰が、何を、どこで、いつ、いくら。
3. 結果を対象企業のカードに整理します。

## 読める公告の種類

| 種類 | わかること | これまでに読んだ数 |
|---|---|---|
| 決算公告 | 提出された年次決算（期限内または遅延） | ~900万件 |
| 変更 | 役員変更、資本、移転 | ~260万件 |
| 設立 | 会社の誕生：資本、住所、設立者 | ~240万件 |
| 抹消 | 活動終了、会社の存続期間 | ~160万件 |
| 集団手続 | 保全手続、更生手続、清算 | ~82万件 |
| 売却・譲渡 | 事業売却：価格、売主、買主 | ~23万件 |
| 登録 | 登記簿への登録、登記所の移転 | ~21万3,000件 |
| 調停 | 和解合意 | ~1 000件 |
| 復活 | 活動への復帰 | ~680件 |
| その他 | 差押え、無効 | わずか |

**合計：2004年以降に公開されたすべての公告が読まれ、整理されています。**
