# 🏠 BODACC.io の舞台裏

BODACC.io は、フランス企業の公式公示を**簡単に調べられる**ようにします。しかし、このデータはどこから来るのでしょうか？ どのようにしてあなたの画面に届くのでしょうか？

舞台裏では、小さな自動ワーカーのチームが毎日働いています。ここに彼らの物語があります。

---

## 🌅 朝：郵便配達員

毎朝、とても早く、私たちの**郵便配達員**が前日の公式公示を取りに行きます：企業の設立、役員の変更、清算、決算書の提出…。彼はそのすべてを、一つも失わずに持ち帰り、私たちの大きな図書館に整理します。

> 👤 **演じるのは Thom** — 取り込みエージェント：毎日公式公示を取得し、データベース用に構造化します。機械を動かしているのは彼です。

→ [郵便配達員の仕事を知る](le-facteur/README.md)

## 📖 次に：翻訳者

公式公示は行政の言葉で書かれたテキストで、読みやすいとは限りません。私たちの**翻訳者**は、それらをすべて読み、わかりやすいカードに変換します：企業名、住所、事業内容、役員、金額…。

→ [翻訳者の仕事を知る](le-traducteur/README.md)

## 🔍 そして：調査員

カードが完成したら、私たちの**調査員**が企業の**公開**情報を補足します：ウェブサイト、電話番号、ソーシャルメディア。プライベートなものも、秘密もありません — 企業自身が公開しているものだけです。

> 👤 **演じるのは Elysa** — エンリッチメント・エージェント：企業カード（ウェブサイト、電話番号、役員のソーシャルメディア）を補完します。公開されているデータだけを取得します：禁止された場所から何かを探すことはありません。

→ [調査員の仕事を知る](lenqueteur/README.md)

## 🧩 同時に：人々のパズル

それぞれの公示は人々について語ります：役員、清算人、会計監査人。私たちの**パズル**は、各人をその企業につなぎ、「誰が何をしているか」を簡単に見つけられるようにします。

→ [人々のパズルを知る](le-puzzle/README.md)

## 🗺️ そして地理学者

私たちの**地理学者**は、各企業が地図（Google Maps）上に本当に存在するかを確認します：住所、カテゴリ、評価。こうして、カードには現実世界での企業の実際の存在も表示されます。

→ [地理学者の仕事を知る](le-geographe/README.md)

## 📚 最後に：契約図書館

公共調達（行政が結ぶ契約）も、私たちの**図書館**に保管されています：100万件以上の契約が、自由に閲覧できます。

→ [契約図書館を知る](la-bibliotheque/README.md)

## 🧭 そして探検家：すべてをまとめる

すべての作業が終わったら、私たちの**探検家**が扉を開きます：ビュー（公示、企業、人物、地域）、その日の統計、そして誰でも見られるまとめを準備します。データをあなたの画面まで届けるのは彼です。

→ [探検家の仕事を知る](lexplorateur/README.md)

## 🔍 ご自身で確認
