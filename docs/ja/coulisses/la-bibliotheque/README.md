# 📚 契約図書館

**仕事**：フランスの**公共調達** — 行政機関、地方公共団体、公的企業が結ぶ契約 — を図書館に整理すること。

各契約は重要な情報とともにアーカイブされます：誰が購入するか、誰が供給するか、いくらの金額か、どのような任務か。

**現在：2015年から現在までの100万件以上の契約。**

## 図書館にあるもの

| 情報 | 詳細 |
|---|---|
| 誰が購入 | 地方公共団体または行政機関 |
| 誰が供給 | 契約を獲得した企業 |
| 金額 | 契約価格 |
| 任務 | 購入されたもの（コードで分類） |
| 日付 | 契約が締結された時期 |

## 彼の約束

| 約束 | 詳細 |
|---|---|
| 完全 | 2015年以降、毎日更新 |
| 公開 | 自由に、無料で閲覧可能 |
| 結び付け | 可能な場合、契約は企業に結び付けられる |
