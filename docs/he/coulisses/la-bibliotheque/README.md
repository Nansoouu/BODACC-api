# 📚 ספריית החוזים

**המקצוע שלו**: לסדר בספרייה שלנו את ה**מכרזים הציבוריים** הצרפתיים — החוזים שנחתמים על ידי הרשויות, הרשויות המקומיות והחברות הציבוריות.
