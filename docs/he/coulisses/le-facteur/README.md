## מה הוא עושה כל יום

1. הוא יוצא לאסוף את ההודעות הרשמיות (הקמות, שינויים, מחיקות, הליכים, מכירות, הגשת דוחות...).
2. הוא מחזיר אותן ומסדר אותן בקפידה בספרייה.
3. הוא מודיע למתרגם: «יש עבודה!»
