# 🧭 החוקר

**המקצוע שלו**: אחרי שהשליח, המתרגם, החוקרת וספרן הספרייה עשו את שלהם, החוקר פותח את הדלתות. הוא הופך את הנתונים שנאספו ל**תצוגות, סטטיסטיקות וסיכומים** שכל אחד יכול לעיין בהם, בלי להיות מומחה.

הוא ה**שלב האחרון** בסיפור שלנו: מי שמביא את הנתונים עד למסך שלך.

## מה הוא עושה כל יום

1. הוא מסדר את ההודעות לפי נושא (הקמות, שינויים, מחיקות, מכירות, הגשת דוחות...) כדי שיהיה קל למצוא אותן.
2. הוא מכין את **המונים בזמן אמת** ואת סיכום היום: כמה הודעות הגיעו, איזו משפחה היא הגדולה ביותר.
3. הוא פותח את דלתות הספרייה לציבור: כרטיסי חברות, אנשים, אזורים, וסיכום היום.
