# 🗺️ הגאוגרף

**המקצוע שלו**: לוודא שכל חברה אכן קיימת על מפת העולם (Google Maps) ולרשום מה שרואים שם: הכתובת, הקטגוריה, הדירוג, מספר חוות הדעת, האתר, הטלפון.
